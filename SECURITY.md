# Security Policy

## Supported versions

Security fixes are provided for the latest released minor version of
`skills-hub`. Pre-release builds and older minor versions may be asked to
upgrade before a fix is prepared.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's **Report a vulnerability** form in the repository Security tab.
Include the affected version, reproduction steps, impact, and any suggested
mitigation. You should receive an acknowledgement within seven days.

Please allow a reasonable remediation and disclosure window before publishing
details. We will coordinate a release and credit reporters who wish to be
acknowledged.
