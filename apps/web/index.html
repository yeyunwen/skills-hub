02

多 Agent 分发

优先使用 symlink，失败时安全回退到 copy；冲突、缺失和同步状态一目了然。

03

本机与 SSH 同构

每台电脑都是独立环境。用相同界面查看技能、Agent 与冲突，并在环境间显式传输。

04

安全地接管目录

覆盖前自动备份，破坏性操作有明确边界。发布产物可通过 SHA256SUMS 与 GitHub attestation 验证。
