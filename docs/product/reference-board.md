# skills-hub UI/UX 参考板

## 核心参考产品

### Codex

用途：

- 本机与 SSH 环境的同级导航。
- 紧凑侧栏、弱边框和低噪音选中态。
- 连接状态作为项目或环境属性，而不是独立功能。
- 原生桌面端窗口质感。

不直接照搬：

- 对话层级和任务模型。
- 与 Skill 管理无关的编辑器布局。

### Visual Studio Code Remote - SSH

用途：

- 连接远程环境后仍提供接近本机的完整能力。
- SSH host、远程文件夹和连接状态的表达。
- 连接中、失败、重新连接和远端不可用等异常流程。

### Linear

用途：

- 高密度资源列表和清晰的信息层级。
- 列表选择、批量操作、右键菜单和命令面板。
- 状态筛选与键盘优先操作。

不直接照搬：

- 过多项目管理概念。
- 针对团队协作设计的复杂状态体系。

### Raycast

用途：

- macOS 原生感、紧凑尺寸和键盘优先交互。
- 搜索、命令面板、快捷操作和轻量弹层。
- 快速反馈而不过度使用装饰动画。

### GitHub Desktop

用途：

- 本地资源与远程状态的关系表达。
- 冲突、不可执行状态和解决入口。
- 危险操作、上下文操作与外部打开动作。

## 真实产品素材平台

以上付费或限额平台不作为项目依赖。无法访问完整内容时，直接使用下面的免费路线。

## 无订阅参考路线

### 公开产品与开源代码

- 用户提供的 Codex 截图作为主要视觉基准。
- Visual Studio Code 与 Remote SSH 作为远程环境语义参考。
- GitHub Desktop 作为列表、冲突和危险操作参考。
- Zed 作为高密度开发者桌面工具参考。
- 开源仓库用于查看真实组件结构、状态处理和响应式实现，不只看营销截图。

### 免费设计规范

- Apple Human Interface Guidelines：macOS 窗口、侧栏、字体、颜色、深色模式和动效原则。
- GitHub Primer：列表、导航、状态、加载、空状态、错误和降级体验。
- Radix Primitives：可访问的无样式交互组件。
- Motion：布局、出现退出和状态反馈动效。

### 免费设计素材

- Penpot Libraries & Templates：公开 UI kit、设计系统、图标和线框模板。
- Lucide：继续作为通用图标基础，并减少同屏彩色图标数量。
- Agent 品牌图标只在辨认工具身份时使用，不作为装饰。

### 项目内自产参考

1. 从公开页面和开源项目中截取与本项目问题直接相关的局部。
2. 为每张参考标注“借鉴什么”和“不借鉴什么”。
3. 基于用户提供的三张截图生成三套原创界面方向。
4. 选定方向后再做交互原型和代码实现。

该流程不要求用户购买任何素材网站订阅。

## 组件与动效来源

### Radix Primitives

- 作为 Dialog、Popover、Dropdown、Tooltip 和 Select 的无样式交互基础。
- 优先保证键盘操作、焦点管理和可访问性。

### shadcn/ui

- 作为可修改的组件源码来源，不把默认主题当作最终视觉。
- 组件应根据 Codex 参考重新定义尺寸、边框、圆角和状态。

### Motion

- 用于环境切换、列表增删、抽屉和状态反馈的轻量动画。
- 动效应服务于位置变化和操作结果，不使用装饰性大动画。

## 不作为主要依据

- Dribbble、Behance：可用于情绪板，但不作为真实任务流程依据。
- 营销落地页画廊：不适合决定桌面工具的信息架构。
- 大量卡片式 SaaS Dashboard 模板：容易延续当前界面卡片过多的问题。
