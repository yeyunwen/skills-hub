# 产品词汇表

本文档用于避免界面文案把不同领域状态混为一谈。标记为“待确认”的术语会在访谈后更新。

| 术语 | 定义 | 推荐文案 | 状态 |
| --- | --- | --- | --- |
| 环境 | 一个可独立扫描、纳管和分发 Skill 的运行位置 | 本机、SSH 设备名 | 待确认 |
| 本机环境 | skills-hub 当前运行的电脑 | 本机 | 已确认 |
| SSH 环境 | 通过 SSH 管理的另一台电脑 | 设备显示名 | 待确认 |
| 统一技能库 | 某个环境中的 `~/.agents/skills` | 统一技能库 | 已确认 |
| 纳管 | 将 Agent 目录中的真实 Skill 安全归入统一技能库 | 纳入技能库 | 推荐方案 |
| 纳管状态 | Skill 是否已进入当前环境的统一技能库并由 skills-hub 管理 | 已纳管、待纳管 | 推荐方案 |
| 分发状态 | 统一技能库中的 Skill 是否已进入目标 Agent 目录 | 已同步、未同步 | 待确认 |
| 冲突 | Agent 目录存在同名但不受 skills-hub 管理的内容 | 冲突 | 已确认 |
| 连接状态 | SSH 环境当前是否可访问 | 已连接、连接中、离线、连接失败 | 待确认 |
| 环境对比 | 比较两个独立环境的统一技能库内容 | 与其他环境对比 | 已确认 |
| 环境传输 | 用户显式选择来源和目标，把 Skill 复制到另一环境 | 传输到… | 已确认 |
| Agent | Codex、Claude、Cursor、OpenClaw 等 Skill 消费端 | Agent / 工具名 | 待确认 |
| 来源 | 可扫描并安装 Skill 的 Git 或本地集合 | 安装来源 | 已有文案 |

## 文案约束

- 不用“待处理”代替“冲突”。
- 不用“已启用”同时表示“已进入统一技能库”和“已分发到 Agent”。
- 连接状态、纳管状态、分发状态分别展示，不合并成一个模糊状态。
- 操作使用动词，状态使用结果词。例如操作叫“同步”，结果叫“已同步”。
- 环境对比结果使用“仅在本机 / 仅在 hermes / 内容不同”，不把任一环境称为主端或从端。
