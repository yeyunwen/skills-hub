# 桌面端窗口与自适应建议

- 状态：Proposed
- 日期：2026-07-26

## 原则

1. 窗口允许自由缩放，但设置能够保持核心任务可用的最小尺寸。
2. 断点由内容开始拥挤或错位的位置决定，不按具体设备型号命名。
3. 小窗口优先改变布局结构，不整体缩小字体和控件。
4. 主内容不产生整页横向滚动；宽表格通过隐藏次要列、详情面板或局部滚动降级。
5. 本机和 SSH 共享组件使用 container query，根据实际内容区域宽度变化。
6. 侧栏、工具栏和主要内容各自拥有明确的滚动边界。

## 建议尺寸

- 默认窗口：`1180 × 760`
- 舒展布局：内容区宽度不小于 `960px`
- 紧凑布局：内容区宽度 `640–959px`
- 窄布局：内容区宽度小于 `640px`
- 建议最小窗口：`720 × 560`

以上数值需要通过真实内容和 macOS 半屏窗口验证后定案。

## 布局降级

### 舒展布局

- 完整侧栏。
- 四列统计摘要。
- 四列 Agent 状态。
- Skill 列表展示名称、描述、路径、状态和主要操作。

### 紧凑布局

- 缩窄侧栏与页面间距。
- 统计摘要调整为两列。
- Agent 状态调整为两列。
- 次要操作进入更多菜单。
- 路径和长描述移入详情区域。

### 窄布局

- 侧栏折叠为图标栏或临时抽屉。
- 统计摘要保持两列或紧凑横排。
- Agent 状态改为单列列表。
- 仅保留名称、关键状态和一个主要操作。
- Dialog 和 Drawer 使用 `viewport - 32px` 的可用宽度。

## 验证矩阵

- `720 × 560`：最小窗口和半屏使用。
- `900 × 650`：紧凑窗口。
- `1180 × 760`：默认窗口。
- `1440 × 900`：宽屏窗口。
- 每个尺寸验证浅色、深色、长设备名、长 Skill 名、离线和冲突状态。
