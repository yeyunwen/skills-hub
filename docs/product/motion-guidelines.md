# 动效范围建议

- 状态：Proposed
- 日期：2026-07-26

## 动效不是全局装饰

动效只用于解释状态变化、保持空间连续性和反馈操作结果，不要求所有功能都动画化。

## 建议范围

### 环境与页面切换

- 切换本机或 SSH 环境时，标题、统计和列表进行短距离淡入过渡。
- Skills、待纳管、目录诊断切换时保持容器位置稳定。

### SSH 连接

- 连接中显示持续但克制的状态指示。
- 扫描、鉴权和读取远端数据可展示分阶段进度。
- 失败后停止循环动效，并明确显示原因与重试入口。

### Skill 操作

- 纳管、同步、传输和移除成功后，对受影响行进行短暂高亮。
- 列表新增、删除、排序和高度变化使用 layout animation。
- 冲突出现时使用颜色与图标变化，不使用抖动等干扰性效果。

### 弹层与导航

- Dialog、Popover、Drawer 和侧栏折叠使用统一进入与退出过渡。
- Hover 和 Press 只提供轻微位移、背景或缩放反馈。

## Motion 对应能力

### Layout animation

适用于：

- 统计区从四列变两列。
- Agent 卡片转换为列表。
- Skill 行新增、删除、排序和展开详情。
- 侧栏宽度变化。

### AnimatePresence

适用于：

- 环境内容切换。
- Dialog、Drawer、Popover 和 Toast 的退出过程。
- SSH 错误、离线提示和重试提示替换。

### Shared layout

适用于：

- 当前环境选中背景在本机和 SSH 行之间平滑移动。
- Skills、待纳管、目录诊断的选中指示器。
- 统计筛选切换后的焦点连续性。

### Reduced motion

适用于：

- 跟随系统减少动效设置。
- 将明显位移替换为短暂淡入淡出。

## 建议特色动效

### 环境切换

左侧选中背景平滑移动，右侧内容保持骨架稳定；旧数据淡出，新数据在连接完成后进入。

### 跨环境传输

在传输面板中明确显示来源环境、Skill 和目标环境。进度沿着来源到目标的关系移动，完成后目标环境状态产生一次短暂高亮。

### SSH 连接

连接圆点依次表达连接中、读取数据、已连接和失败，不让整个页面重复闪烁或重新布局。

特色动效控制在一到两个场景，其余功能使用统一的轻量反馈。

## 时间建议

- Hover、Press：`80–120ms`
- 小型状态切换：`120–180ms`
- Dialog、Drawer、布局变化：`180–240ms`
- SSH 等待状态：循环动效持续存在，但不移动主要内容

具体时长需要在原型中感受后调整。

## 可访问性与性能

- 跟随系统 Reduced Motion 设置。
- Reduced Motion 下取消位移、缩放和布局动画，保留必要的透明度与颜色反馈。
- 优先使用 opacity 和 transform。
- 不为静态装饰持续运行动画。
- Motion 按需加载，避免为了少量微交互引入不必要的运行成本。
