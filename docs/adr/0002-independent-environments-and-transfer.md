# ADR-0002：环境独立与跨环境传输

- 状态：Accepted
- 日期：2026-07-26

## 背景

skills-hub 需要同时管理本机和多台 SSH 设备。跨电脑使用者希望方便地比较和传输 Skill，但这不应让远程设备变成本机的附属目标。

## 决策

1. 本机与每台 SSH 设备都是独立且平等的环境。
2. 每个环境默认使用自己的 `~/.agents/skills` 作为 Hub，并拥有独立的 Agent 目录状态和安装来源；本机 Hub 路径可以配置，SSH Hub 当前固定使用默认路径。
3. 默认环境页面只展示并操作当前环境的数据。
4. 跨环境对比与传输作为显式工具保留，不出现在默认 Skills 主流程中。
5. 对比必须明确来源环境和目标环境，不隐含“本机是真源”。
6. 传输默认是用户触发的复制操作，不自动建立持续双向同步。
7. 目标环境存在同名内容时进入冲突流程，不能静默覆盖。

## 结果

- SSH 环境能够像本机一样独立工作。
- 多设备用户仍可快速复制和比较 Skill。
- 产品不需要维护“本机管理”和“远程同步”两套核心模型。
- 自动同步、版本合并和双向同步不属于当前决策范围。
