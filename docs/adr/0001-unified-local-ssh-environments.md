# ADR-0001：本机与 SSH 使用统一环境导航

- 状态：Accepted
- 日期：2026-07-23

## 背景

当前桌面端将“本机管理”和“远程设备”设计为不同功能。用户进入 SSH 环境前，需要先进入远程设备页，再选择设备。远程页还维护了一套与本机不同的对比、传输和同步界面。

这导致：

- SSH 比本机多一级入口。
- 本机与远程使用不同页面和状态语言。
- 相同的 Skill 管理能力需要维护两套交互。
- 用户需要先理解设备类型，再理解 Skill 管理任务。

## 决策

1. 将本机和每台 SSH 设备统一建模为“环境”。
2. 所有环境在左侧导航中处于同一层级。
3. 点击环境后直接进入该环境的 Skills 页面。
4. SSH 环境复用本机环境的页面结构、统计摘要和主要操作。
5. SSH 特有信息只作为环境状态补充，例如连接状态、主机名称和重新连接。
6. 整体视觉与交互语言参考 Codex：紧凑、弱边框、列表优先、减少卡片嵌套。

## 结果

- 不再需要“远程设备”作为独立主导航。
- 本机和 SSH 共享同一套页面组件与状态模型。
- 连接管理成为环境级能力，不侵入 Skill 的核心操作。
- 跨环境对比和传输是否保留，由后续 ADR 决定。
